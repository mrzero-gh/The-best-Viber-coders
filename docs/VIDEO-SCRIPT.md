# Сценарий демо-видео (2:45)

Запись экрана с голосом: OBS или Win+G. Терминал на весь экран, крупный шрифт (18–20 pt), тёмная тема.

**Подготовка.** Перед записью выполнить эти команды один раз, чтобы потом не ждать на камере:

```powershell
.venv\Scripts\activate
python -m scripts.check --docker      # около 3 минут; на видео покажем только итог
python -m scripts.jury                # прогрев
```

Медленные команды (`check --docker`, `jury`) лучше записать отдельно и в монтаже ускорить ×4–×8 или оставить только последний экран.
